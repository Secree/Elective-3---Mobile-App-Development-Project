Hello World Flutter App

This is a minimal Flutter project that displays "Hello World" centered on the screen.

Prerequisites
- Install the Flutter SDK and ensure `flutter` is on your PATH.
- An Android device or emulator set up.

Quick start (PowerShell on Windows):

```powershell
# from project root
cd "c:\Users\Pc\OneDrive\Documents\Coding Practice\Flutter\hello_world_app"
# get dependencies
flutter pub get
# if platform folders are missing, run (this will generate android/ ios folders):
# flutter create .
# run on an attached Android device or emulator
flutter run -d android
```

If you don't have Flutter installed yet, download it from https://flutter.dev and follow the setup instructions.
